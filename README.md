# Superstore Sales Performance Analysis Using Data Analytics

## Project Description

This project analyzes Superstore retail sales data using Python-based
data analytics techniques. The project focuses on sales trends,
profitability, product performance, customer segments, regional
performance, and discount analysis.

The project follows a complete data analytics workflow starting from
data loading and cleaning to exploratory analysis, visualization, and
business insight generation.

## Objectives

- Analyze overall sales and profit performance.
- Identify sales trends over time.
- Analyze category and sub-category performance.
- Compare regional performance.
- Analyze customer segments.
- Identify top-performing products.
- Examine discount and profit relationships.
- Generate meaningful business insights.

## Dataset

The project uses the Superstore Sales Dataset obtained from Kaggle.

Dataset Link:

https://www.kaggle.com/datasets/himanshuuike/superstore-sales-dataset

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
